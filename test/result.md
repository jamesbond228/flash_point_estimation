# Marrero-Gani法 沸点推算の検証結果

## 1. 結論

- 実測沸点（Book1.csv）97件で検証した。第3近似の平均絶対誤差（MAE）は 10.91 K、平均相対誤差（ARE）は 2.85%。
- 論文の適用範囲である炭素数3以上（78件）に限ると、MAE 7.38 K、ARE 1.84%、R² 0.975。炭素数2以下（19件）は MAE 25.37 K、R² 0.508 と大きく劣る。
- 第1次から第3次へ進むほど誤差は減る（全体 MAE: 13.16 → 11.56 → 10.91 K）。
- 誤差は小分子ほど大きく、符号は主に過小推算（bias はすべての条件で負）。
- 論文表のとおり計算しても、化合物によっては 30〜60 K ずれる。外れ値の原因（論文表の寄与値、グループ分解の解釈、実測値の側）は切り分けていない。

## 2. 検証条件

### 2.1 データ

- 入力: `Book1.csv`（113行、列は化合物名・`BoilingPont`・`FlashPoint`）。
- 実測沸点は摂氏と見なし、K に換算（+273.15）して比較した。圧力の記載があるグリセリン以外は、常圧の値と仮定している。
- 実測値の出典と測定条件は不明。

### 2.2 SMILES

- Book1.csv に SMILES の列がないため、化合物名から手作業で SMILES を割り当てた（`validate_tb.py` の `NAME_TO_SMILES`）。自動変換ではない。
- 割り当てを検証するための外部データベースとの照合は行っていない。取り違えの確認は利用者側で必要（出力CSVの `smiles` 列）。

### 2.3 実測値の解釈

| 表記 | 扱い |
|---|---|
| 単一の数値（例: `78.3`、`290.0℃`） | そのまま採用 |
| 範囲（例: `117–118`） | 中点を採用（`tb_exp_kind = range`） |
| `約202` | 202 を採用（`tb_exp_kind = approx`） |

### 2.4 推算の設定

- 推算器: `marrero_gani_tb.py`（Tb = 222.543 × ln(Σ寄与)、第3近似を最終値とする）。
- 寄与値: 論文 Table 6〜8 のCSV（Tb1i, Tb2j, Tb3k）。
- 未割当原子がある化合物は推算しない（既定の `error`）。

### 2.5 評価対象

| 区分 | 件数 |
|---|---|
| 全行 | 113 |
| 評価対象（推算成功・実測あり・除外なし） | 97 |
| 推算不能 | 4 |
| 混合物・略称のみ・継ぎ足し行などで除外 | 12 |

除外した行の内訳は次のとおり。

| 化合物 | 除外理由 |
|---|---|
| Ligroin、Petroleum Benzine 3種 | 混合物（石油留分） |
| Xylene | 異性体混合物 |
| Ethanol(95) | 95%水溶液。純エタノールとして推算したが評価に含めない |
| 1,1,2-TCA、TEA、TFA | 略称のみの行（値なし） |
| 名前のない3行 | グリセリンの圧力表記が別行に分かれたもの |

## 3. 結果

### 3.1 全体

| 条件 | N | MAE [K] | RMSE [K] | bias [K] | ARE [%] | R² |
|---|---|---|---|---|---|---|
| 全評価対象（第3近似） | 97 | 10.91 | 16.91 | -4.12 | 2.85 | 0.927 |
| status = ok のみ | 96 | 11.00 | 17.00 | -4.19 | 2.87 | 0.926 |
| 実測が単一値のみ | 85 | 11.66 | 17.89 | -4.67 | 3.06 | 0.921 |
| 実測が単一値かつ status = ok | 84 | 11.77 | 17.99 | -4.75 | 3.09 | 0.920 |
| 炭素数3以上 | 78 | 7.38 | 9.95 | -3.64 | 1.84 | 0.975 |
| 炭素数2以下 | 19 | 25.37 | 32.46 | -6.13 | 6.99 | 0.508 |

bias は 推算 - 実測 の平均。ARE は実測 [K] に対する相対誤差の平均。status = uncertain は1件（テトラリン。論文の範囲外にあたるグループ例外の適用）。

### 4.3 グループ分解の確認

誤差の大きい6化合物（テトラクロロエチレン、トリフルオロ酢酸、トリエタノールアミン、安息香酸ベンジル、酸化プロピレン、エタノールアミン）で、使われたグループと寄与値を確認した。論文のルール（重いグループ優先、第2・3次の重なり規則）に沿った分解であり、明らかな割り当て誤りは見つからなかった。ただし、論文に記載のない解釈（groups.py の判断記録 D1〜D9 以降）を含むため、実装と論文の差が誤差に寄与している可能性は排除できない。

## 5. 推算できなかった化合物

第1次グループに該当する定義がなく、原子が未割当になるため推算不能（`error`）。

| 化合物 | 未割当の原子 |
|---|---|
| 無水酢酸 | C, O |
| 二硫化炭素 | S, C, S |
| N,N-ジメチルホルムアミド | N, C, O |
| ホルムアミド | N, C, O |

これらは論文の Table 6 に対応するグループがない構造で、groups.py の適用範囲外（D9）に当たる。

## 6. 制約・注意

- 実測値の出典・測定条件が不明なため、誤差の一部が実測値側にある可能性がある。
- SMILES は手作業の割り当てで、外部データベースとの照合をしていない。
- 実測値の範囲表記は中点で近似している（`range` の行は最大で範囲の幅の半分程度の誤差を含みうる）。
- 論文の寄与値CSV（Table 6〜8）は、Appendix B の例題で使う値の一致を確認済み。全件のPDF照合は未実施。
- 炭素数別の件数が少ない区分（炭素数9以上）では、統計の信頼性が低い。
- 検証は113行のデータセット内で完結している。他のデータへの一般化は未確認。

## 7. 成果物と再現

| ファイル | 内容 |
|---|---|
| `Book1_with_pred.csv` | 元データに推算値・誤差・status などの列を追加したCSV |
| `validate_tb.py` | 検証スクリプト（SMILES対応表、実測値の解釈、指標の集計を含む） |
| `marrero_gani_tb.py` | 沸点推算の本体 |

追加した列: `smiles`, `tb_exp_c`, `tb_exp_kind`, `tb_exp_k`, `n_carbon`, `tb_pred_k`, `tb_pred_c`, `tb_1st_k`, `tb_2nd_k`, `err_k`（推算 - 実測）, `err_pct`, `tb_status`, `tb_messages`, `eval_use`, `exclude_reason`

再現手順:

```bash
python validate_tb.py Book1.csv -o Book1_with_pred.csv
```

`marrero_gani_groups.py`、`marrero_gani_batch.py`、`Table_6.csv`、`Table_7.csv`、`Table_8.csv` を同じディレクトリに置くこと。依存パッケージは RDKit、pandas、numpy。

## 8. 今後の候補

- 外部の実測沸点データを追加し、評価件数を増やす。
- MG法の推算値や第1〜3次のグループ数を特徴量にした、誤差補正の回帰モデルを作る。ただし現状の有効97件では学習データが少ない。
- 炭素数2以下の誤差が大きい化合物について、論文表の寄与値とグループ分解の実装を個別に突き合わせる。
- SMILES の割り当てを外部データベースで照合する。
